# Файловые дескрипторы: сжатие пробелов

Напишите фильтр stdin → stdout, заменяющий каждую максимальную серию байтов ASCII 0x20 одним пробелом. Остальные байты копируются без изменений, включая NUL и LF. Используйте read и write для данных, обрабатывайте EINTR и короткие записи. Работайте блоками с O(1) дополнительной памятью и сохраняйте состояние между блоками. Успех — 0, ошибка ввода-вывода — ненулевой статус.

`printf 'a   b  \n' | ./solution` выдаёт байты `a b \n` (перед LF один пробел).

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g solution.c -o solution
```

Сдавайте `solution.c`. Заготовка компилируется и возвращает 1 до реализации.
