# Ассемблер: серии единиц

Реализуйте `uint32_t bit_runs(uint64_t x)` на x86-64. Верните число максимальных непрерывных серий единичных битов в 64-битном представлении x. Используйте целочисленные регистры, битовые инструкции и переходы. Не вызывайте функции из ассемблера.

| x | Результат |
|---|---:|
| 0 | 0 |
| 0x3B | 2 |
| 0xAAAAAAAAAAAAAAAA | 32 |
| 0xFFFFFFFFFFFFFFFF | 1 |

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g check.c solution.S -o check
./check
```

Сдавайте `solution.S`. Сборка рассчитана на Linux x86-64 и System V AMD64 ABI. `check.c` содержит короткую проверку примера и до реализации возвращает 1.
