# mmap: самая длинная строка

Интерфейс: `./solution FILE`. Отобразите регулярный файл через mmap. Напечатайте номер первой самой длинной строки (с 1) и её длину в байтах, не включая LF. LF завершает строку, непустой хвост без LF тоже считается строкой. NUL считается обычным байтом. Пустой файл даёт `0 0` без mmap нулевой длины. Используйте O(1) дополнительной памяти. Входной файл не меняется во время работы. При ошибке завершитесь с ненулевым кодом.

Файл с байтами `a\nxyz\n123` даёт `2 3`.

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g solution.c -o solution
```

Сдавайте `solution.c`. Заготовка компилируется и возвращает 1 до реализации.
