# Сигналы: отчёт по запросу

Создайте однопоточную программу. Заблокируйте SIGUSR1 и SIGTERM, создайте signalfd, затем напечатайте PID и сбросьте буфер stdout. На каждый прочитанный SIGUSR1 печатайте порядковый номер уведомления с 1 и сбрасывайте буфер. На SIGTERM завершайтесь с кодом 0 без дополнительного вывода. Все строки завершаются LF. Используйте signalfd для обоих сигналов и блокирующее ожидание без опроса. Драйвер посылает следующий USR1 только после получения предыдущей строки.

Запустите `./solution` в первом терминале. Во втором выполните `kill -USR1 PID`, дождитесь строки 1, повторите для строки 2, затем `kill -TERM PID`. Подставьте PID своей программы.

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g solution.c -o solution
```

Сдавайте `solution.c`. Заготовка компилируется и возвращает 1 до реализации.
