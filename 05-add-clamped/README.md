# Ассемблер: сложение массивов с насыщением

Реализуйте `size_t add_clamped(int16_t *dst, const int16_t *src, size_t n)` на x86-64. Для каждой пары вычислите математическую сумму, ограничьте её диапазоном [−32768, 32767] и запишите в dst. Верните число сумм, которые пришлось ограничить. Массивы не пересекаются. При n=0 указатели могут быть NULL. Сохраните регистры, которые требует System V AMD64 ABI. Используйте скалярные целочисленные инструкции.

Например, для dst=[32000, −32000, 7], src=[1000, −1000, −2] получаем dst=[32767, −32768, 5] и результат 2.

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g check.c solution.S -o check
./check
```

Сдавайте `solution.S`. Сборка рассчитана на Linux x86-64 и System V AMD64 ABI. `check.c` содержит короткую проверку примера и до реализации возвращает 1.
