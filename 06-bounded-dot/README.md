# SSE2: скалярное произведение с ограничением

Реализуйте `float bounded_dot(const float *a, const float *b, size_t n)` на x86-64. Для каждого i ограничьте a[i] диапазоном [−1, 1], умножьте на b[i] и сложите произведения. Используйте упакованные SSE-инструкции для полных групп из четырёх элементов и обработайте остаток без чтения за концом массивов. SSE2 — верхняя граница набора инструкций. Массивы могут быть не выровнены на 16 байт. При n=0 верните +0. В тестах n≤4096, все элементы конечны, abs(b[i])≤10. Допуск относительно эталона в double — абсолютная ошибка ≤0.02.

Для a=[2,−4,0.5], b=[3,2,4] ответ 3.

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g check.c solution.S -o check
./check
```

Сдавайте `solution.S`. Сборка рассчитана на Linux x86-64 и System V AMD64 ABI. `check.c` содержит короткую проверку примера и до реализации возвращает 1.
