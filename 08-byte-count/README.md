# Процессы: подсчёт вывода команды

Интерфейс: `./solution PROG [ARG ...]`. Запустите команду через fork и execvp без shell. Перенаправьте stdout ребёнка в pipe, оставьте stderr и stdin без перенаправления. Родитель читает до EOF, считает байты и затем ждёт ребёнка. Напечатайте `BYTES STATUS` с LF. STATUS — обычный код или 128+номер сигнала. При отказе exec ребёнок завершает работу с 127. При успехе работы родителя его код 0 вне зависимости от STATUS. При ошибке самого запуска/чтения/ожидания родитель возвращает ненулевой код. В тестах команда и её потомки закрывают stdout, объём помещается в uint64_t.

`./solution printf hello` → `5 0`. Проверят также вывод больше буфера канала.

## Сборка

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g solution.c -o solution
```

Сдавайте `solution.c`. Заготовка компилируется и возвращает 1 до реализации.
